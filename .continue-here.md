## Current State

### What's Working
- **FUSE-T NFS mount works** on FUSE-T 1.0.54 (downgraded from 1.2.0 which has libfuse3 ABI incompatibility with fuser 0.17)
- `echo "hello" > /mount/test.txt` — writes work
- `cat /mount/test.txt` — reads work
- `ls /mount/` — directory listing works
- Mount stays alive, doesn't crash or exit
- Auto-creates mountpoint directory if missing

### What's NOT Working
- **FUSE-T 1.2.0** — "Invalid request" / immediate session termination. Root cause: libfuse3 profile=v3 ABI breaks fuser 0.17. Need to stay on 1.0.54 until fuser updates.
- **FSKit backend** — fuse-t.app 1.2.0 extension toggle is greyed out in System Settings. Can't enable. Needs Apple/fuse-t fix.
- **SMB backend** — Bonjour service discovery (`fuse-t._smb._tcp.local`) fails on this machine (exit 66).
- **`cp` across mount** — macOS NFS kernel bug (FUSE-T Issue #45). Deadlocks on simultaneous read+write fds. Not fixable from FUSE daemon side.
