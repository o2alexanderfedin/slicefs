The plan checker split the old tracer plan in two, so this plan leads with its own tracer task for the run file path, and 17-03 leads with the tracer of the whole store.

Output: run.rs, the run and MANIFEST kinds in pack_io.rs, mem.rs and retry.rs, run.rs unit tests.

1. crates/chunk-store/src/pack_io.rs [Disk I/O path]:
   - Add Kind::Run (file name {num:016x}.run) and Kind::Manifest (file name MANIFEST; callers pass num 0). pack_name returns these names.
   - FileIo keeps FileIo::new(pack_dir). It puts the index files in the sibling directory pack_dir.with_file_name("index"), that is STORE/index [Layout: runs + MANIFEST]. read, write_durable, remove and exists route the two new kinds to that directory. prepare(false) makes both directories; prepare(true) answers for the pack directory only and makes nothing. sync_dir syncs the pack directory and, if it exists, the index directory.

3. crates/chunk-store/src/retry.rs: forward list_runs and open_run; create_run returns the inner handle wrapped like create (RetryingPack), so a failed run sync is retried with the copy of the unsynced bytes.
4. crates/chunk-store/src/run.rs (new; pub(crate) items) [Layout: entry 58 B + 8-byte fence] [Layout: sort order] [Rehash #62 / tag byte]:
   - Entry bytes: the 33-byte ObjectId, pack u64 LE, offset u64 LE, stored u32 LE, raw u32 LE, flags u8: 58 bytes. A tombstone is an entry with flags bit 0x80 set; its pack field is the pack whose entry it hides; offset, stored and raw are 0. Loc flags use only bit 0 (FLAG_ZSTD), so bit 0x80 is free.
   - Page: 4096 bytes: count u16 LE, two zero bytes, CRC32C u32 LE of the entry bytes, then at most 70 entries ((4096 - 8) / 58), then zero padding. Entries are sorted by the full 33-byte ID compared bytewise (the existing ObjectId Ord: tag, then digest). A new tag always starts a new page.
   - After the pages: the tag table (per tag: tag u8, first page u64, page count u64), the fence table (8 bytes per page: digest bytes 0..8 of the first entry of the page), the filter block (empty in this plan; 17-05 adds it), then a fixed-size footer: magic SFRN, run format version u16 = 1, filter type u8 (0 = none; 17-05 adds 1 = blocked Bloom), bits per key u8, entry count u64, tombstone count u64, page count u64, then offset u64, length u64 and CRC32C u32 for each of the tag table, the fence table and the filter, then the smallest and largest pack number of the put entries, then a CRC32C of the footer.
   - RunWriter: takes the expected entry count, streams sorted entries into a file made with create_run, keeps one page and the trailer tables in RAM, writes with write_at, calls sync after each 64 MiB written and at the end (so the RetryingIo copy stays at most one pack size), and returns the file length and the entry and tombstone counts.
   - Run::open(handle, num, len): reads the footer at len minus the footer size; checks the magic, the version and the CRC; checks every offset, length and count against len with checked arithmetic (refuse with Error::Corrupt, never panic, as decode_index does for its count); reads the tag table and the fence table into RAM. It never reads a page.
   - Run::get(id) returns Result of Option of an entry (Put Loc or tombstone pack): the tag table gives the page range of the ID's tag; a binary search of the fences in that range gives the last page whose fence is at most the first 8 digest bytes of id; one read_at of that 4 KiB page; a page CRC mismatch is Error::Corrupt naming the run and the page (never None); a binary search in the page. If the ID's 8-byte prefix equals the page fence and the page is not the first of its tag range, also search the previous page (two keys with the same 64-bit prefix can sit across a page boundary).
   - Run::iter(): reads the pages in order, one at a time, and yields Result of each entry; a damaged page yields Error::Corrupt and ends the iteration (never skips a page).
5. crates/chunk-store/src/lib.rs: declare mod run with an allow(dead_code) attribute (the store uses the module from 17-03, which removes the attribute).
6. The tracer test (unit test in run.rs) a_run_round_trips_through_each_io: for MemIo, for FileIo on TEMPDIR/packs (prepare(false) first), and for RetryingIo::with_backoff over a MemIo with an empty backoff list: write 1,000 sorted entries with RunWriter into create_run(1), drop the writer, then open_run(1) and Run::open with the returned length; every key is found with its exact entry; a key that was never written is not found; each get does exactly one read_at (wrap the PackRead in a small counting wrapper in the test).
