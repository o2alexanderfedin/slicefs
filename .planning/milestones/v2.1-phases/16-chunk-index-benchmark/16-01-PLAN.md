<objective>
Build the standalone index benchmark `benchmarks/index-bench`: a bin crate that makes chunk stores of N small synthetic objects through the public ChunkStore API and measures, each in a fresh process, the open time and peak RSS of `ChunkStore::open_with` (through `ChunkStore::open`), hit and miss lookup throughput, and the recovery time and scan throughput of packs without an `.idx`. A `run` driver starts the binary once per step and prints markdown tables.

The tests in cli_tests.rs run in CI with `cargo test --workspace`. They are tests of the tool on small stores and assert no timing. No measurement runs in CI; the deferred item "CI integration of the benchmark" stays deferred.

Facts from the code (read at planning time, HEAD ba34257):
- `ChunkStore::open(dir, opts)` (crates/chunk-store/src/lib.rs:450) wraps `open_with` with `RetryingIo` over `FileIo::new(dir.join("packs"))`. Packs are `<dir>/packs/<16 hex>.pack` and `.idx` (`pack_io::pack_name(num, Kind::Idx)`, both public).
- `open_with` (lib.rs:456-532) reads each `.idx` fully, decodes it, and inserts each entry into `Inner.index: HashMap<ObjectId, Loc>` with no reserve. A pack without a valid `.idx`: if it is the LAST pack and not punched, it becomes the active pack (`scan_pack`, CRC only, no hash check, cut and sync, NO new idx); otherwise `resync_scan` (CRC + BLAKE3 check of every record) and `write_durable` of a new idx. A read-only open (`Options::read_only`) skips the cut and the idx write.
- `put` (lib.rs:536) hashes with BLAKE3, then a dedup check under the mutex. `contains` (lib.rs:841) is one mutex lock and one map probe. `close` (lib.rs:863) seals the active pack. `stats()` (lib.rs:894) gives exact `objects` and `packs`.
- An 8-byte payload is below MIN_COMPRESS (64), so zstd never runs. Record = 54 B, idx entry = 50 B. Default `pack_limit` is 64 MiB: about 1.24M records per pack, so a store of up to about 1.24M objects has ONE pack.
- The idx header is magic (4 bytes), version (u16 LE), entry count (u64 LE at bytes 6..14), see `encode_index` (lib.rs:337).
- libc 0.2.191 (Cargo.lock) has `task_info`, `mach_task_basic_info`, `MACH_TASK_BASIC_INFO`, `MACH_TASK_BASIC_INFO_COUNT` on Apple targets; `mach_task_self()` is marked deprecated (it points to the mach2 crate), so the helper needs `#[allow(deprecated)]`.
