<objective>
Write-log RAM, option A (14-CONTEXT.md "Write-log RAM", spike on local branch
spike/wal-memory). Per-op writes each operation record into the kernel at
once (no fsync). Flush-on-fsync and periodic write their buffer to the
segment (no fsync) when it passes 4 MiB. Periodic gets its timer. The number
of fsync calls does not change. Help text, module docs, the Phase 05c Docker
control and docs/design/write-log.md state the new crash rules.
</objective>
