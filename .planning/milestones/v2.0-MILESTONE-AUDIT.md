# v2.0 Milestone Audit (re-run, 2026-11-17)

## Re-run, 2026-11-17 (after PRs #79, #81, #83)

**Status: TECH DEBT.** All 21 requirements are accounted for, all 6 phases
are verified, and all 5 E2E flows complete. No gap stays open.

The integration checker read the code and ran 6 test suites with no mount
(`write_log_replay_tests`, `streaming_tests`, `crash_recovery_tests`,
`gc_online_tests`, `signal_tests`, `fsync_tests`). It found 1 blocker and
2 warnings. PR #94 fixes all three, with 3 new tests that failed before the
fix; `cargo test --workspace` passes.

| Finding | Severity | Fix |
|---|---|---|
| commit_cut did not sync the bytes it logged again after it deleted the old segments (`--wal flush-on-fsync`): fsync'd Buffered bytes lost at a crash after a commit | Blocker | PR #94: sync after the re-log |
| utimens between a write and the close lost at close | Warning | PR #94: an explicit mtime wins |
| write replied EBADF for every error | Warning | PR #94: real errno |
| stat of an open file showed the old mtime | Suspicion | PR #94: overlay the write time |
| Full re-log of large Buffered files at each commit | Performance | Issue #93 |

Requirements 3-source check: each requirement has VERIFICATION `passed`,
a SUMMARY `requirements-completed` entry (added for 07.1-02, 07.1-03,
12-01 and 12-02 in this re-run) and a traceability row (9 Complete,
12 Superseded).

## First run (2026-11-17)

## Update, 2026-11-17: gaps closed

- FUSET-05 is fixed (PR #59): a sigaction handler writes to a self-pipe, and a
  thread unmounts the mount point, so destroy() does the final commit. A
  second signal exits at once; signals ignored at start stay ignored.
  verify-phases.sh checks SIGTERM, SIGINT (Ctrl+C) and SIGHUP on a live
  mount: the process exits, mount.lock is gone, the write is kept.
- Dead code removed: the watchdog, the fuse-t.ini fallback, dir_size,
  is_replaying (PR #59); the unused slicefs-compression crate and the
  Compressor trait, the CLI store_io re-export.
- The binary now uses the library instead of compiling every module a
  second time: no lib-only dead-code warnings, and the module tests run once.
  The workspace builds with no warnings outside the vendored fuser.
- Planning: the traceability rows are synced (PR #72). Each of the 6 v2.0
  VALIDATION.md files is closed with the tests that cover it, or marked
  superseded where the phase code was replaced (closed_reason in each file).
