## Test Infrastructure

| Property | Value |

---

## Sampling Rate

- **After every task commit:** the touched test file plus `cargo clippy -p <crate> --all-targets -- -D warnings` for the touched crate. `cargo test --workspace` must exit 0 before any commit.
- **After every plan wave:** `scripts/safety/model.sh`, `scripts/safety/kani.sh` and the race tests. Miri and TSan run on a `ci/**` push by the orchestrator.
- **Before `/gsd-verify-work`:** all `safety.yml` jobs green on the feature branch (orchestrator push), the Docker coverage log shows `build-exit=0`, and `ci.yml` is green.
- **Max feedback latency:** 120 seconds for the quick run.
