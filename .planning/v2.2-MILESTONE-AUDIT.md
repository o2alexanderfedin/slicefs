## Integration (cross-phase)

All 10 checks are wired:
- one store header for the profile and the hash flag;
- all commands open through `content::open_inner`;
- a different profile is refused;
- rehash keeps the profile;
- rehash uses the offline lock, the `mount.lock` check and the write-log check;
- the hash flag is on disk before the first new object;
- online, offline and rehash GC share the bounded mark;
- prolly is isolated from the product crates;
- the dirty budget has loom models together with the pool;
- the safety gates run at release.

## Flows

- **seed, mount with N workers, write, unmount, rehash, mount, scrub and gc:** complete at the code level. Tests cover each part. No single test runs the whole chain (G1).
- **rehash crash, then a rerun:** complete. Each step has a crash test.
