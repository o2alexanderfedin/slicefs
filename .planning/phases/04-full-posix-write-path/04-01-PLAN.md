Add three public methods:
- `increment_refcount(&self, digest: &Digest224)` -- lock refcounts, entry(digest).or_insert(0) += 1
- `decrement_refcount(&self, digest: &Digest224)` -- lock refcounts, decrement, remove entry if reaches 0
- `get_refcount(&self, digest: &Digest224) -> u64` -- lock refcounts, return *entry or 0

Initialize `refcounts: Mutex::new(BTreeMap::new())` in `new()`.

In `commit()`, intern refcount blob via `State::push_all` to get a `refcount_data: Digest224`. Expand root record from 156 bytes to 184 bytes (add refcount_data as 7th Digest224 at offset 156). In `load_from_root()`, read the refcount_data digest at offset 156-184, load the blob via GetBytes, deserialize back into BTreeMap.

Guard backward compat: if root.bin is exactly 156 bytes (old format), treat refcounts as empty BTreeMap. Only the new 184-byte format includes refcounts.

Write tests in `crates/metadata/tests/refcount_tests.rs`.

7. Update `destroy()` to persist dictionary and root after commit:
```rust
fn destroy(&mut self) {
    if let Ok(root) = self.meta.commit() {
        let dict = self.dict.lock().unwrap();
        let bytes = serialize_dictionary(&*dict);
        drop(dict);
        if let Some(ref store_path) = self.store_path {
            let _ = std::fs::write(store_path.join("dictionary.bin"), &bytes);
            let mut root_bytes = Vec::with_capacity(28);
            for word in &root {
                root_bytes.extend_from_slice(&word.to_le_bytes());
            }
            let _ = std::fs::write(store_path.join("root.bin"), &root_bytes);
        }
    }
}
```
