    - Test: release() increments refcount for the content digest
    - Test: writing two identical files results in shared content (same Digest224 in manifests)

  </behavior>
  <action>
**create() implementation:**
Replace the EROFS stub. Use `req.uid()` and `req.gid()` for ownership. Build `InodeMeta::new_file(0, uid, gid, S_IFREG | (mode & !umask & 0o7777))`. Call `meta.create_inode(&meta)`. Call `meta.link(parent.0, name_str, ino)`. Allocate a write handle: `fh = next_fh.fetch_add(1, Relaxed) + 1`. Insert `OpenFileState { ino, buf: vec![] }` into open_files. Call `inode_to_file_attr` on the created inode. Reply with `reply.created(&TTL, &attr, Generation(0), FileHandle(fh), FopenFlags::empty())`.

Error handling: if create_inode fails, reply.error with mapped errno. If link fails, delete the created inode and reply.error.

**write() implementation:**
Replace the EROFS stub. Lock open_files, get_mut by fh.0. If not found, reply.error(EBADF). Calculate `end = offset as usize + data.len()`. If `end > buf.len()`, `buf.resize(end, 0)`. Copy data: `buf[offset as usize..end].copy_from_slice(data)`. Reply with `reply.written(data.len() as u32)`.

**release() implementation:**
Replace the current empty release. If `fh.0 == 0` (read-only handle), just reply.ok(). Otherwise, remove the entry from open_files. If the buffer is non-empty: lock dict briefly for `State::push_all(&mut *dict, &buf)` to get content_digest, drop dict lock. Call `meta.set_manifest(ino, &[content_digest])`. Call `meta.increment_refcount(&content_digest)`. Update inode: get_inode, set size = buf.len(), update mtime_sec/mtime_nsec to current time (`SystemTime::now().duration_since(UNIX_EPOCH)`), update ctime similarly, call update_inode. If buffer is empty (empty file): set_manifest with empty slice `&[]`, update inode size to 0. Reply ok.

CRITICAL: Drop the dict lock BEFORE any meta.* call to avoid deadlock (DictMetadataStore internally acquires dict lock).

Also update `read()`: if the file handle is in open_files (file is open for writing), read from the buffer instead of from the manifest/GetBytes path. This enables read-after-write within the same open session.

**Tests** in `crates/slicefs-cli/tests/write_path_tests.rs`: Use `DictMetadataStore::new()` and `Dictionary::default()` to construct `SliceFsFilesystem` directly (not via FUSE mount). Call the meta store methods directly to simulate the create/write/release pipeline, then verify content via GetBytes. The `macos-no-mount` feature compiles fuser Filesystem trait without actual mount.

  <action>
**setattr() implementation:**
Replace the EROFS stub with a full implementation handling each optional field:

1. Load the inode: `meta.get_inode(ino.0)`. On error, reply.error.
2. If `mode` is Some: update `inode.mode = (inode.mode & S_IFMT) | (mode & 0o7777)` (preserve type bits, update permission bits).
3. If `uid` is Some: update `inode.uid`.
4. If `gid` is Some: update `inode.gid`.
5. If `mtime` is Some(TimeOrNow): update `inode.mtime_sec` and `inode.mtime_nsec`. For `TimeOrNow::Now`, use `SystemTime::now()`. For `TimeOrNow::SpecificTime(t)`, convert from SystemTime.
6. If `size` is Some (TRUNCATE path):
   a. If `fh` is Some and the fh is in open_files: truncate/extend the in-flight buffer directly. `buf.resize(size as usize, 0)` handles both shrink and extend.
   b. If `fh` is None or not in open_files (file is closed): read current content via GetBytes (using manifest), truncate/extend the Vec<u8>, re-push through State::push_all, update manifest. Decrement refcount for old content, increment for new content.
   c. Update `inode.size = size`.
7. Always update `inode.ctime_sec`/`ctime_nsec` to now (ctime changes on any metadata change).
8. Call `meta.update_inode(&inode)`.
9. Reply with updated attr: `reply.attr(&TTL, &inode_to_file_attr(&inode))`.

**mknod():** Replace EROFS with ENOSYS (mknod for device nodes/fifos not supported). Regular file creation goes through create().

Add truncate tests to `write_path_tests.rs`.
