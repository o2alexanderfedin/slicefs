**mkdir() implementation:**
Replace EROFS stub. Build `InodeMeta::new_directory(0, req.uid(), req.gid(), S_IFDIR | (mode & !umask & 0o7777))`. Set nlinks=2 (. and ..). Call `meta.create_directory(parent.0, name_str, &dir_meta)` which handles inode creation, . and .. entries, and parent dir entry. On success, get the inode, increment parent nlinks: `get_inode(parent.0)`, `parent_inode.nlinks += 1`, `update_inode(&parent_inode)`. Reply with `reply.entry(&TTL, &attr, Generation(0))`.

**rmdir() implementation:**
Replace EROFS stub. Lookup name in parent to get ino. Verify it's a directory (`get_inode(ino).mode & S_IFDIR`). List directory entries -- must be exactly 2 (. and ..). If more, return ENOTEMPTY. Call `meta.unlink(parent.0, name_str)`. Call `meta.delete_inode(ino)`. Remove from dir_data (need to check if delete_inode handles this, or if we need a separate dir cleanup). Decrement parent nlinks: `get_inode(parent.0)`, `parent_inode.nlinks -= 1`, `update_inode`. Reply ok.

Note: DictMetadataStore's unlink removes the directory entry. delete_inode removes from inode_data and inode_map. The dir_data entry for the removed directory may need manual cleanup -- check if delete_inode handles it. If not, add a `remove_directory_data` method or clear dir_data entry in the rmdir implementation.

**unlink() implementation:**
Replace EROFS stub. Lookup name in parent to get ino. Get inode. Verify it's NOT a directory (return EISDIR if it is -- use rmdir for directories). Call `meta.unlink(parent.0, name_str)`. Decrement `inode.nlinks`. If nlinks reaches 0: get manifest, for each digest call `meta.decrement_refcount(&digest)`, call `meta.delete_inode(ino)`. If nlinks > 0: `meta.update_inode(&inode)`. Reply ok.

Guard: check `inode.nlinks > 0` before decrementing to prevent u32 underflow.

**link() implementation:**
Replace EROFS stub. Get source inode to verify it exists. Verify source is not a directory (POSIX disallows hard links to directories, return EPERM). Call `meta.link(newparent.0, newname_str, ino.0)`. Increment `inode.nlinks`. Update ctime. `meta.update_inode(&inode)`. Reply with `reply.entry(&TTL, &attr, Generation(0))`.

Write tests in `crates/slicefs-cli/tests/dir_link_tests.rs`. Use direct `DictMetadataStore` method calls to exercise the pipeline (no FUSE mount needed).

**rename() implementation:**
Replace EROFS stub.

1. If `flags.contains(RenameFlags::RENAME_EXCHANGE)`, return `reply.error(Errno::ENOSYS)`.
2. Lookup `name` in `parent` to get `src_ino`. If not found, reply ENOENT.
3. If `flags.contains(RenameFlags::RENAME_NOREPLACE)`: check if `newname` exists in `newparent`. If yes, reply EEXIST. If no, proceed.
4. Check if `newname` exists in `newparent`: if yes, call `meta.unlink(newparent.0, newname_str)` to remove old target. If old target's nlinks reaches 0, decrement refcounts and delete inode (same logic as unlink). Get the target inode first to manage nlinks.
5. Call `meta.link(newparent.0, newname_str, src_ino)` to add new entry.
6. Call `meta.unlink(parent.0, name_str)` to remove old entry.
7. If renaming a directory and parent != newparent: update the directory's `..` entry (need to update dir_data to point .. at newparent). Also adjust nlinks: old parent nlinks--, new parent nlinks++. This is complex -- if DictMetadataStore doesn't expose dir_data mutation for .., consider adding a `reparent_directory(&self, ino, new_parent)` helper method to store.rs that updates the .. entry.
8. Update ctime on the moved inode.
9. Reply ok.

For the directory .. reparent case: if this is too complex for Phase 4, document it as a known limitation and handle flat renames only for directories initially. Cross-dir file renames (the critical editor pattern) must work fully.

**symlink() implementation:**
Replace EROFS stub. Create `InodeMeta` with mode `S_IFLNK | 0o777`, nlinks=1, uid/gid from request. Create inode via `meta.create_inode`. Link into parent via `meta.link(parent.0, link_name_str, ino)`. Store target as content: convert `target.as_os_str().as_encoded_bytes()` to bytes, lock dict, `State::push_all(&mut *dict, target_bytes)`, drop dict. Set manifest: `meta.set_manifest(ino, &[content_digest])`. Increment refcount. Update inode size = target_bytes.len(). Reply with entry.

**readlink() implementation:**
The EROFS stubs don't include readlink since it's a read op. Check if readlink exists in the current code. If not, add it. Load manifest for ino, use GetBytes to read all content bytes, convert to OsString, reply.data(&bytes).

Add rename and symlink tests to `dir_link_tests.rs`.
