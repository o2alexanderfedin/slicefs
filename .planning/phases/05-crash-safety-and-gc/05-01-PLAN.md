Create `crates/metadata/src/wal/` module with files:

**mod.rs** — Trait definition and config:
```rust
pub trait WalStrategy: Send + Sync {
    fn log_mutation(&self, entry: &WalEntry) -> Result<(), WalError>;
    fn flush_and_sync(&self) -> Result<(), WalError>;
    fn shutdown(&self) -> Result<(), WalError>;
}

pub enum WalEntry {
    DictionaryAppend { key: Digest224, branches: Branches },
    RootUpdate { root: Digest224 },
}

pub enum WalConfig {
    PerOp,
    Periodic { interval_secs: u64 },
    FlushOnFsync,
    NoWal,
}
```
- `WalError` as a thiserror enum with Io, SegmentError variants
- `pub fn create_wal(config: WalConfig, store_path: &Path, segment_id: u64) -> Result<Box<dyn WalStrategy>, WalError>` factory function

**no_wal.rs** — `NoWal` struct implementing WalStrategy. All methods return Ok(()).

**per_op.rs** — `PerOpWal` struct:
- Holds `Mutex<SegmentWriter>` (the current active segment)
- `log_mutation`: convert WalEntry to SegmentEntry, call writer.write_entry(), then writer.sync()
- `flush_and_sync`: call writer.sync()
- `shutdown`: call writer.close()

**flush_on_fsync.rs** — `FlushOnFsyncWal` struct:
- Holds `Mutex<Vec<WalEntry>>` buffer + `Mutex<SegmentWriter>`
- `log_mutation`: push entry to buffer, return Ok (no disk I/O)
- `flush_and_sync`: drain buffer, write all entries to segment, sync
- `shutdown`: flush remaining buffer, close writer

**periodic.rs** — `PeriodicWal` struct:
- Holds `Mutex<Vec<WalEntry>>` buffer + `Mutex<SegmentWriter>`
- `log_mutation`: push entry to buffer
- `flush_and_sync`: drain buffer, write, sync (same as FlushOnFsync — the periodic checkpoint is done by a timer in the background GC thread in Plan 04)
- `shutdown`: flush remaining, close
