Create `.github/workflows/ci.yml` with a single workflow containing two jobs:

**Linux job (`linux`):**
- `runs-on: ubuntu-latest`
- Steps:
  1. `actions/checkout@v4`
  2. Install system deps: `sudo apt-get update -q && sudo apt-get install -y libfuse-dev fuse`
  3. Enable user FUSE access: `sudo modprobe fuse && sudo chmod 666 /dev/fuse`
  4. `cargo test --workspace` -- runs all unit and integration tests
  5. `cargo build -p slicefs-cli --release` -- build the binary for pjdfstest mount
  6. Install pjdfstest: `cargo install pjdfstest` (Rust rewrite from saidsay-so/pjdfstest, installable via cargo)
  7. Mount SliceFS for pjdfstest:
     ```yaml
     - name: pjdfstest POSIX compliance (>95% gate)
       run: |
         # Create a temporary store and mount point
         STORE_DIR=$(mktemp -d)
         MOUNT_DIR=$(mktemp -d)

         # Mount SliceFS in the background
         ./target/release/slicefs mount "$MOUNT_DIR" --store "$STORE_DIR" &
         SLICEFS_PID=$!
         sleep 2

         # Verify mount is live
         mountpoint -q "$MOUNT_DIR" || { echo "FUSE mount failed"; kill $SLICEFS_PID 2>/dev/null; exit 1; }

         # Run pjdfstest with a skip list for known <5% failures
         # Known skips: chown root-only tests, mknod for special files, sticky bit enforcement
         # These require CAP_CHOWN / root ownership which FUSE filesystems cannot provide
         pjdfstest "$MOUNT_DIR" \
           --skip chown/00 \
           --skip mknod/11 \
           --skip sticky \
           2>&1 | tee pjdfstest-results.txt

         TOTAL=$(grep -c "^ok\|^not ok" pjdfstest-results.txt || echo 0)
         PASS=$(grep -c "^ok" pjdfstest-results.txt || echo 0)

         # Unmount
         fusermount -u "$MOUNT_DIR" || kill $SLICEFS_PID 2>/dev/null
         wait $SLICEFS_PID 2>/dev/null || true
         rm -rf "$STORE_DIR" "$MOUNT_DIR"

         # >95% compliance gate
         if [ "$TOTAL" -gt 0 ]; then
           RATE=$(( PASS * 100 / TOTAL ))
           echo "pjdfstest compliance: $PASS/$TOTAL ($RATE%)"
           if [ "$RATE" -lt 95 ]; then
             echo "FAIL: pjdfstest compliance $RATE% is below 95% gate"
             exit 1
           fi
         else
           echo "WARNING: No pjdfstest results found"
           exit 1
         fi
     ```
  NOTE: The exact pjdfstest CLI flags (especially --skip) may differ from the above. The executor should check `pjdfstest --help` after installation to confirm the skip syntax. The saidsay-so/pjdfstest Rust rewrite supports TOML config files for skip lists -- if `--skip` flags are not supported, create a `pjdfstest.toml` config file instead with the skip list. The key requirement: run pjdfstest against a live mount, compute pass rate, fail CI if below 95%.

Create the `benchmarks/` directory with fio job files and a runner script.

**fio job files** (4 files):

1. `sequential_write.fio` -- sequential write with 4K blocks, 4 jobs, 4GB total, `ioengine=sync`, `direct=1`, `end_fsync=1`. The `directory` parameter is overridden at runtime by the script. Target: 200 MB/s on NVMe.

2. `sequential_read.fio` -- sequential read, same parameters but `rw=read`. Reads files created by a prior write pass.

3. `random_read.fio` -- random read, `rw=randread`, `bs=4k`, `size=1g`, `numjobs=4`.

4. `small_files.fio` -- small file create/delete workload: `rw=write`, `bs=4k`, `size=4k`, `nrfiles=1000`, `numjobs=1`. Tests metadata-heavy operations.

All job files use `[global]` section with `group_reporting=1` and a `directory=${MOUNT_DIR}` placeholder (fio supports `--directory` override on CLI).

**run_benchmarks.sh:**
```bash
#!/usr/bin/env bash
set -euo pipefail

MOUNT_DIR="${1:?Usage: $0 <mount-dir> [results-dir]}"
RESULTS_DIR="${2:-./results}"

mkdir -p "$RESULTS_DIR"
DATE=$(date +%Y%m%d-%H%M%S)

for job in benchmarks/*.fio; do
    name=$(basename "$job" .fio)
    echo "Running: $name"
    fio "$job" --directory="$MOUNT_DIR" \
        --output-format=json \
        --output="$RESULTS_DIR/${name}_${DATE}.json"
    echo "  -> $RESULTS_DIR/${name}_${DATE}.json"
done

echo "All benchmarks complete. Results in $RESULTS_DIR/"
```
Make executable: `chmod +x benchmarks/run_benchmarks.sh`.
