    **Step 4 -- Simplify scrub.rs:**

    The old scrub iterates `dict.iter()` to verify SHA-224 hashes per entry. After migration, there is no in-memory Dictionary to iterate.

    Simplified approach: For each live root (from segments), verify that `file_storage_get(io, &root)` returns valid data. This checks that the batch file exists and the Merkle tree structure is intact. The Merkle tree's hash-chain guarantees that if `file_storage_get` succeeds, all nodes in the chain are valid.

    ```rust
    pub fn run_scrub(store_path: &Path, json: bool) -> Result<(), Box<dyn std::error::Error>> {
        let (root_opt, snapshots) = load_store_from_segments(&segs_dir)?;

        let mut io = StoreIo::new(store_path);
        let mut roots_verified = 0usize;
        let mut corrupted = Vec::new();

        // Collect all roots to verify
        let mut roots: Vec<Digest224> = Vec::new();
        if let Some(root) = root_opt {
            roots.push(root);
        }
        for snap in &snapshots {
            roots.push(snap.root);
        }

        // Verify each root resolves through FileStorage
        for root in &roots {
            match file_storage_get(&mut io, root) {
                Some(_bytes) => {
                    roots_verified += 1;
                    // Root resolves correctly -- Merkle chain is intact
                }
                None => {
                    corrupted.push(format!("missing or corrupt root {:?}", root));
                }
            }
        }

        // Additionally, verify metadata sub-trees by loading from root
        // This exercises all intern/load round-trips
        if let Some(root) = root_opt {
            let io_arc = Arc::new(Mutex::new(StoreIo::new(store_path)));
            match DictMetadataStore::load_from_root(io_arc, &root) {
                Ok(_meta) => { /* metadata tree intact */ }
                Err(e) => {
                    corrupted.push(format!("metadata tree corrupt: {}", e));
                }
            }
        }

        // Print report (same format as before, adapted for new metrics)
    }
    ```

    Note: This is a semantic change from per-entry hash verification to root-resolution verification. It is equivalent in correctness because Merkle tree integrity guarantees that if the root resolves, all children are valid. Per-entry verification of batch files is not needed and would require parsing the internal batch file format which blockset does not export a public deserializer for.

    fn dir_size(dir: &Path) -> u64 {
        let mut total = 0u64;
        if let Ok(entries) = std::fs::read_dir(dir) {
            for entry in entries.flatten() {
                let meta = entry.metadata().ok();
                if let Some(m) = meta {
                    if m.is_file() {
                        total += m.len();

                        total += dir_size(&entry.path());

                }
            }
