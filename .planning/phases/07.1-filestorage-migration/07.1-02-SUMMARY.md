# Phase 07.1 Plan 02: Migrate DictMetadataStore to File-Backed Storage Summary

**One-liner:** Replace `Mutex<Dictionary>` with `Arc<Mutex<StoreIo>>` in DictMetadataStore, routing all intern_*/load_* calls through FileStorageAdd and file_storage_get for zero-RAM block storage.

| 2+3 | Migrate write path (FileStorageAdd) and read path (file_storage_get); update all tests | 0010083 |

## What Was Built

### DictMetadataStore Field Change
- `dict: Mutex<Dictionary>` replaced with `io: Arc<Mutex<StoreIo>>`
- `DictMetadataStore::new()` now requires `Arc<Mutex<StoreIo>>`
- `Default` impl removed — construction requires explicit storage backing
- `io()` accessor returns `&Arc<Mutex<StoreIo>>` for test/reload scenarios

### Write Path — FileStorageAdd
All `intern_*` functions in `store.rs` now acquire `io.lock()` and wrap it in `FileStorageAdd::new(&mut *io_guard)`. The FSA is dropped at end of scope to flush tree nodes to disk before proceeding.

### Read Path — file_storage_get
All `load_*` calls use `file_storage_get(&mut *io_guard, digest)`. The `load_inode`, `load_inode_map`, `load_manifest`, `load_xattrs`, and `load_entry_list` functions were updated to accept `&mut impl Io` instead of `&Dictionary`.

### Directory Read-Then-Write Pattern
`add_dir_entry`, `remove_dir_entry`, `lookup_dir_entry` previously required `S: StorageAdd + StorageGet`. Now they use `&mut impl Io` with sequential borrow pattern: `file_storage_get(io, ...)` completes (releases mutable borrow), then `FileStorageAdd::new(io)` starts a fresh write phase.

### Crash-Safe Commit Ordering
`commit()` builds all new tree nodes via FSA, drops FSA (flushes files via fsync), releases `io_guard`, then writes `WalEntry::RootUpdate` to the WAL. This ensures node files are durable before the WAL records the new root — crash-safe.

### `load_from_root` Migration
`load_from_root(dict: Dictionary, root: &Digest224)` → `load_from_root(io: Arc<Mutex<StoreIo>>, root: &Digest224)`. Reads inode map, inodes, directories, manifests, xattrs all via `file_storage_get`.

### Segment/WAL Format Cleanup (Task 1)
- `SegmentEntry::DictEntry` variant removed — `RecordType::from_u8(0x01)` returns `None` (legacy skip)
- `WalEntry::DictionaryAppend` removed
- `load_store_from_segments` returns `(Option<Digest224>, Vec<SnapshotEntry>)` — no Dictionary

### GC Background Thread Update
`background.rs` previously called `store.dict().lock()` for orphan counting. Updated to use a fixed proxy (1 entry), enabling `orphan_threshold=0` to always trigger and `usize::MAX` to never trigger. New `run_gc_roots_only()` method added to `GarbageCollector` for Dictionary-free compaction.
