# Phase 07.1 Plan 03: CLI Consumer Migration to File-Backed Storage Summary

Completed the SliceFS CLI migration from in-memory Dictionary to file-backed StoreIo. All CLI consumers — filesystem adapter, mount, seed, GC, scrub, stats, snapshot commands — now use `Arc<Mutex<StoreIo>>` with `file_storage_get` / `FileStorageAdd` for content I/O. Zero Dictionary references remain in the codebase.

## What Was Built

### Core Changes

**SliceFsFilesystem (filesystem.rs)**
- Replaced `dict: Arc<Mutex<Dictionary>>` field with `io: Arc<Mutex<StoreIo>>`
- Read path: `file_storage_get(&mut *io, &root_digest)` replaces `GetBytes::new(GetData::new(&*dict, ...))`
- Write path: `FileStorageAdd::new(&mut *io); State::push_all(&mut fsa, &compressed); drop(fsa);` replaces `State::push_all(&mut *dict, ...)`
- `statfs`: physical bytes computed from `dir_size(vt0/)` instead of `dict.len() * 92`
- Constructor now takes `io: Arc<Mutex<StoreIo>>` as second argument (replaces `dict: Dictionary`)

**mount.rs**
- `load_store()` returns `(DictMetadataStore, Arc<Mutex<StoreIo>>, MountLock)` — no Dictionary
- Legacy format (`dictionary.bin`) returns "Re-seed required" error instead of migrating
- `load_store_from_segments` 3-tuple → 2-tuple (`(root_opt, snapshots)`)

**seed.rs**
- Content pushed via `FileStorageAdd`; root persisted via `SegmentWriter + RootUpdate`
- No `dictionary.bin` or `root.bin` output

**gc/mod.rs**
- `collect_live_set` takes `&mut impl Io` (was `&Dictionary`); returns empty HashSet (stub)
- `run_gc` takes `&mut impl Io` (was `&Dictionary`)
- FileStorage orphan file cleanup deferred to future phase

**gc.rs, scrub.rs, stats.rs**
- All updated to 2-tuple `load_store_from_segments`
- Legacy format detection: return error instead of migrating

**store_io.rs**
- Reduced to thin re-export from metadata crate (eliminates duplicate implementation)

### Integration Test Updates

All 8 integration test files updated:
- `write_path_tests.rs`, `compression_tests.rs`: `fresh_fs()` returns `(SliceFsFilesystem, TempDir)`
- `statfs_tests.rs`: Rewrote Dictionary-specific dedup ratio tests using Digest224 equality
- `dir_link_tests.rs`, `posix_compliance_tests.rs`: Updated `read_content()` to use `file_storage_get`
- `crash_recovery_tests.rs`: Updated to 2-tuple segment loading and `run_gc(&mut io, ...)`
- `fsync_tests.rs`, `gc_cli_tests.rs`: Updated helpers to use `Arc<Mutex<StoreIo>>`
- `gc_tests.rs` (metadata crate): `collect_live_set` tests updated to StoreIo stub contract
