<objective>
Clear the runway before the first map becomes a tree: retire every prolly-bench mode that reads the flat maps of a product store, keep the product-code `whole` mode and the synthetic modes, and fix review item IN-05 (`--l` default 8192). Without this, the first tree conversion (plan 26-04) would break `cargo test --workspace` through `smoke_end_to_end`.

Task 1 changes the bench code and its smoke test. Task 2 updates the scripts and the README and runs the gates.

Decisions this plan implements (26-CONTEXT.md): "Decided autonomously: [Commit] ... also fix IN-01 ... and IN-05 (bench --l default 8192)" (IN-05 here; IN-01 in plan 26-04); "Decided autonomously: [Bench] ... flat baseline with a v2.3.0 binary" (the flat-store modes live on in the v2.3.0 tag); the owner rule of no store backward compatibility.

Discretion choice (record in the SUMMARY): retire, not port. A port of `batches`/`maps` to trees would need new record formats (inline inode values, entries by name) for modes whose only job (the Phase 24/25 one-map comparisons) is done and recorded in `docs/research/prolly-trees.md` and the Phase 25 runs.

Purpose: keep the workspace green across the format change; prepare `bench.sh` for PMAP-07 check C.
Output: the trimmed bench, updated scripts and README, `runs/gate-26-03.log`.
</objective>
