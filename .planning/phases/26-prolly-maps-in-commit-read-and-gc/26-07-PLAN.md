<objective>
Convert the two small maps by the pattern of plan 26-04: `refcounts` (a read-modify-write map keyed by content key) and `xattr_data` (inline or spilled values).

Task 1 converts `refcounts` with its rehash and a concurrency test. Task 2 converts `xattr_data` with the inline/spill value, the GC refs of spilled sets and rehash, and runs the gates.

Decisions this plan implements (26-CONTEXT.md "On-disk format"): "an xattr set goes inline in `xattr_data` when the entry fits `MAX_ENTRY` (2,048 bytes) and spills to a separate object (value = `ObjectKey`) when it does not"; "`refcounts` keep content key -> 8-byte count"; "xattr values carry a 1-byte tag (inline set or spilled `ObjectKey`)"; and "Scope: rehash is ported to rebuild the trees".

Discretion choices (record in the SUMMARY): tag 0 = inline set, tag 1 = spill; the inline set bytes are today's xattr set encoding; the refcount count is u64 LE; refcount overlay shards by the first bytes of the key digest.

Purpose: PMAP-03 and PMAP-06 for two more maps.
Output: two trees, tests, `runs/gate-26-07.log`.
</objective>
