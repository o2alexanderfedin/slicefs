<objective>
Add what the product needs from `crates/prolly` before any map moves into it: a bounded node cache, a seek/range cursor (readdir), O(1) `count` and `height`, and a node visitor with node IDs (GC mark, rehash). No product code changes; no node byte or boundary changes.

Task 1 adds `NodeCache` and `Ctx` and routes every read through them. Task 2 adds `range`, `count`, `height` and `visit`.

Decisions this plan implements (26-CONTEXT.md "Decided autonomously"): "[Read path] read on demand from prolly nodes through a bounded node cache"; "[Read path] Node cache size: fixed byte cap" (the cap value and the option come in plans 26-04 and 26-06); "[GC] a stack of one node path per tree" (`visit` holds one path).

Discretion choices (record in the SUMMARY): LRU eviction by a tick; a node is charged its encoded length plus 64 bytes per entry plus 128; the cache lock is `chunk_store::sync::Mutex` at `Rank::Store`, held only for map operations (no read, decode or callback under it).

Purpose: PMAP-03 (read on demand, bounded) and PMAP-06 (node IDs for the mark).
Output: `cache.rs`, `range.rs`, `visit.rs`, the `Ctx` read path, tests, `runs/gate-26-02.log`.
</objective>

    - `range` on a depth-3 tree holds at most depth nodes (`max_nodes_held`).
    - `count` equals the number of `iter` entries; `height` equals 1 + the highest `walk` level; both read one node (cache misses == 1 on a cold cache).
    - `visit` yields each node of the tree exactly once (the IDs equal the IDs reached by a reference recursion over `walk` levels, as a multiset) with leaf entries equal to `iter`; returning false at the 3rd node stops with `Ok(false)` after 3 calls; the empty tree gives one leaf with no entries.
    - a crafted tree whose child count does not match gives `Error::Corrupt` from `range`, `count` (overflowing counts) and `visit`.
  </behavior>
  <action>
1. `range.rs`: `range` descends from the root to the first child whose last key >= `start` at each level (binary search, as `get`), keeping the per-node lower bound of `Cursor` so every loaded child gets the same parent-entry checks; then moves forward like `Cursor` and stops at the first key >= `end`. `count`: leaf -> entries; internal -> checked sum of the child counts (`Error::Corrupt` on overflow). `height`: root level + 1.
2. `visit.rs`: depth-first, left to right, one path of `Arc<Node>`; for each node call `f(&NodeVisit { id, level, children, entries })` (entries empty for an internal node); load children with `load_child` (checks); return `Ok(false)` as soon as `f` returns false.
