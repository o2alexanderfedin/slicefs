  <name>Task 1: Remove compression from filesystem.rs core</name>
  <files>crates/slicefs-cli/src/filesystem.rs</files>
  <action>
Remove all compression infrastructure from SliceFsFilesystem. This is the largest single change.

1. **Remove imports** (top of file):
   - Delete `use slicefs_compression::{compress_block, decompress_block};`
   - Delete `use slicefs_traits::compressor::Compressor;`

2. **Remove struct fields** from `SliceFsFilesystem`:
   - Delete `compressor: Arc<dyn Compressor>,`
   - Delete `store_version: u32,`
   - Update the doc comment on the struct to remove the compressor/store_version paragraphs (lines ~67-75)

3. **Update constructor** `SliceFsFilesystem::new`:
   - Remove `compressor` and `store_version` parameters
   - Remove those fields from the `Self { ... }` initializer
   - New signature: `pub fn new(meta: DictMetadataStore, io: Arc<Mutex<StoreIo>>, store_path: Option<PathBuf>) -> Self`

4. **Delete methods** `to_wire_bytes` and `from_wire_bytes` entirely (lines ~329-355).

5. **Update all 7 call sites** that used `to_wire_bytes`/`from_wire_bytes` — replace with direct byte passing:
   - `flush_buffer_to_cas`: replace `let wire_bytes = self.to_wire_bytes(&buf);` with passing `&buf` directly to `State::push_all`. Avoid the `.clone()` — pass `&buf` as a slice.
   - `test_read` (pub helper): replace `let raw_bytes = self.from_wire_bytes(wire_bytes);` with `let raw_bytes = wire_bytes;`
   - FUSE `read` callback: same pattern — `from_wire_bytes` call becomes direct use of the bytes.
   - Symlink write path (~line 901): replace `self.to_wire_bytes(target_bytes)` with direct byte use (`target_bytes.to_vec()` or pass slice).
   - Symlink read path: replace `self.from_wire_bytes(wire_bytes)` with direct use.
   - Any other call site found by grep for `to_wire_bytes` or `from_wire_bytes`.

   **Anti-pattern to avoid:** Do NOT allocate a `wire_bytes = buf.clone()` when you can pass `&buf` directly. `State::push_all` takes `&[u8]`, so `&buf` works.

6. **Update flush_buffer_to_cas** specifically — this is the critical write path:
   ```rust
   // BEFORE:
   let wire_bytes = self.to_wire_bytes(&buf);
   let digest = State::push_all(&mut fsa, &wire_bytes);

   // AFTER:
   let digest = State::push_all(&mut fsa, &buf);
   ```
