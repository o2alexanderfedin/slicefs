    - list_xattr_names returns all set xattr names

    - Empty xattr set serializes and deserializes correctly (no xattrs = no data)
    - Large xattr values (> 31 bytes, triggers CAS tree storage) round-trip correctly
    - Multiple xattrs on same inode coexist independently
    - DictMetadataStore.set_xattr/get_xattr/list_xattrs/remove_xattr work end-to-end
  </behavior>
  <action>
  1. Create `crates/metadata/src/xattr.rs`:
     - Xattr storage model: a set of (name, value) pairs serialized as a flat byte stream stored in a CAS tree.
     - Entry format: `[name_len: u32 LE][name_bytes][value_len: u32 LE][value_bytes]` concatenated.
     - `pub fn intern_xattrs(dict: &mut impl StorageAdd, xattrs: &[(String, Vec<u8>)]) -> Digest224` -- serialize all pairs, push_all into dict. For empty list, push_all with empty bytes (returns a canonical empty digest).
     - `pub fn load_xattrs(dict: &impl StorageGet, key: &Digest224) -> Result<Vec<(String, Vec<u8>)>, MetaError>` -- get bytes, deserialize entries
     - Helper functions that operate on a loaded xattr list:
       - `pub fn set_xattr_entry(xattrs: &mut Vec<(String, Vec<u8>)>, name: &str, value: &[u8])` -- insert or replace
       - `pub fn get_xattr_entry(xattrs: &[(String, Vec<u8>)], name: &str) -> Option<Vec<u8>>` -- lookup by name
       - `pub fn list_xattr_names(xattrs: &[(String, Vec<u8>)]) -> Vec<String>` -- return all names
       - `pub fn remove_xattr_entry(xattrs: &mut Vec<(String, Vec<u8>)>, name: &str) -> bool` -- remove if exists, return whether removed
     - Unit tests for all behaviors

  2. Update `crates/metadata/src/store.rs`:
     - Add `xattr_data: Mutex<BTreeMap<u64, Digest224>>` field to DictMetadataStore (maps ino -> xattr tree digest)
     - Replace xattr stub methods with real implementations:
       - `set_xattr`: load existing xattrs (or empty vec), call set_xattr_entry, intern_xattrs, store digest in xattr_data
       - `get_xattr`: load xattrs from xattr_data digest, call get_xattr_entry. Return MetaError::NotFound if ino not in inode_data or xattr name not found.
       - `list_xattrs`: load xattrs, call list_xattr_names. Return empty vec if no xattrs set.
       - `remove_xattr`: load xattrs, call remove_xattr_entry, re-intern, update xattr_data. Return MetaError::NotFound if name not found.
     - Initialize xattr_data as empty BTreeMap in DictMetadataStore::new()

  3. Update `crates/metadata/src/lib.rs`:
     - Add `pub mod xattr;`

  4. Write integration tests in store.rs for xattr:
     - test_xattr_set_get: set xattr on file inode, get returns same value
     - test_xattr_list: set multiple xattrs, list returns all names
     - test_xattr_remove: set then remove, subsequent get returns error
     - test_xattr_overwrite: set same name twice, get returns second value
     - test_xattr_on_directory: xattrs work on directory inodes too
     - test_xattr_large_value: value > 31 bytes round-trips (exercises CAS tree path)

  Verify with `cargo test -p metadata`.

    - After reload: next allocated inode number continues from where it left off (no reuse)
    - Dictionary serialize + deserialize + load_from_root produces identical state
  </behavior>
  <action>
  1. Update `crates/metadata/src/store.rs`:
     - Refine `commit()` implementation:
       - Serialize inode_map via intern_inode_map, get inode_map_root Digest224
       - Serialize all in-memory state maps (inode_data, dir_data, manifest_data, xattr_data) as part of a root record
       - Root record format (binary, LE):
         ```
         [inode_map_digest: 28 bytes (Digest224)]
         [root_dir_ino: 8 bytes (u64)]
         [next_ino: 8 bytes (u64)]
         [inode_data_digest: 28 bytes (Digest224)]  -- serialized BTreeMap<u64, Digest224>
         [dir_data_digest: 28 bytes (Digest224)]     -- serialized BTreeMap<u64, Digest224>
         [manifest_data_digest: 28 bytes (Digest224)] -- serialized BTreeMap<u64, Digest224>
         [xattr_data_digest: 28 bytes (Digest224)]   -- serialized BTreeMap<u64, Digest224>
         ```
         Total: 156 bytes. Serialize each BTreeMap<u64, Digest224> as `[count: u64][entries: (u64, Digest224)...]` and intern via push_all.
       - Push root record via State::push_all, return the root Digest224

     - Add `pub fn load_from_root(dict: Dictionary, root: &Digest224) -> Result<Self, MetaError>`:
       - Get root record bytes from dict via GetBytes
       - Parse inode_map_digest, root_dir_ino, next_ino, and all data map digests
       - Load inode_map via load_inode_map
       - Load each BTreeMap<u64, Digest224> from its digest
       - Reconstruct DictMetadataStore with all fields populated
       - Verify root_dir_ino is in inode_data (sanity check)

     - Add helper: `fn intern_u64_digest_map(dict: &mut impl StorageAdd, map: &BTreeMap<u64, Digest224>) -> Digest224`
       - Serialize as `[count: u64 LE][for each: u64 LE ino + 28 bytes Digest224]`
       - Push via State::push_all

     - Add helper: `fn load_u64_digest_map(dict: &impl StorageGet, key: &Digest224) -> Result<BTreeMap<u64, Digest224>, MetaError>`
       - Get bytes, parse count, then count entries of 36 bytes each
