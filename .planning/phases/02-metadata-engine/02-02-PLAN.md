pub type Digest224 = [u32; 7];
pub type Digest256 = [u32; 8];
pub type Branches = [Digest256; 2];
pub type Dictionary = BTreeMap<Digest224, Branches>;
pub trait StorageAdd { fn add(&mut self, left: &Digest256, right: &Digest256) -> Digest256; fn end(&mut self, x: &Digest256) -> Digest224; }
pub trait StorageGet { fn get(&self, key: &Digest224) -> Option<Branches>; }

  2. Create `crates/metadata/src/directory.rs`:
     **CRITICAL: Per-entry CAS subtrees per user decision (CONTEXT.md locked decision). Do NOT use flat linear serialization.**

     Each directory is represented as a set of individual (key, value) entries in the Dictionary:
     - Entry key: `Digest224` computed by `State::push_all(dict, name.as_bytes())` -- the CAS hash of the entry name
     - Entry value: inode number encoded as `Digest256` via `blockset::from_bytes(&ino.to_le_bytes())` -- 8 bytes always fits inline in Digest256

     The directory itself is tracked by a "directory entry list" -- a serialized list of Digest224 entry keys stored as a CAS tree. This list is needed to enumerate all entries (for list_directory) since individual entry keys are scattered in the Dictionary.

     Helper functions (pub for testing, used by all dir operations):
     - `pub fn entry_key(dict: &mut impl StorageAdd, name: &str) -> Digest224` -- compute name hash via `State::push_all(dict, name.as_bytes())`
     - `pub fn ino_to_digest256(ino: u64) -> Digest256` -- `blockset::from_bytes(&ino.to_le_bytes()).unwrap()`
     - `pub fn digest256_to_ino(d: &Digest256) -> u64` -- `u64::from_le_bytes(blockset::to_data(d).try_into().unwrap())`

     Directory representation in DictMetadataStore:
     - `dir_data: BTreeMap<u64, Digest224>` maps ino -> directory entry list digest
     - The entry list digest points to a CAS tree of serialized `[(name_key: Digest224, name_bytes_len: u32, name_bytes: [u8])]` records so we can reconstruct names during listing
     - Each individual entry's value (the inode number) is stored separately in Dictionary as `dict[name_key] = [ino_digest256, EMPTY]` using `StorageAdd::end()` on the ino_digest256

     Public functions:
     - `pub fn create_dir_entries(dict: &mut impl StorageAdd, self_ino: u64, parent_ino: u64) -> Digest224`
       Creates . and .. as two separate entries in dict. Each entry: compute entry_key for "." / "..", store ino via `dict.end(&ino_to_digest256(ino))` which creates `(entry_key, [ino_d256, EMPTY])` in dict. Serialize the entry list (2 entries with their name_keys and name strings) via State::push_all. Return the entry list digest.

     - `pub fn add_dir_entry(dict: &mut impl StorageAdd + StorageGet, dir_digest: &Digest224, name: &str, ino: u64) -> Result<Digest224, MetaError>`
       1. Load existing entry list from dir_digest
       2. Check if name already exists in list -- return MetaError::AlreadyExists if so
       3. Compute entry_key for name, store ino in dict via end(&ino_to_digest256(ino))
       4. Append new entry record to list, re-serialize entry list via State::push_all
       5. Return new entry list digest
       NOTE: Only the entry LIST is re-serialized (lightweight -- just Digest224 keys + short name strings). The actual entry VALUES are individual Dictionary nodes that are NOT re-serialized.

     - `pub fn remove_dir_entry(dict: &mut impl StorageAdd + StorageGet, dir_digest: &Digest224, name: &str) -> Result<Digest224, MetaError>`
       1. Load entry list, find and remove entry by name. Reject removing "." or "..".
       2. Re-serialize entry list without the removed entry. Return new digest.
       3. Return MetaError::NotFound if name not in list.
       NOTE: The removed entry's Dictionary node becomes unreachable (GC handles cleanup in Phase 5).

     - `pub fn lookup_dir_entry(dict: &mut impl StorageAdd + StorageGet, dir_digest: &Digest224, name: &str) -> Result<u64, MetaError>`
       1. Compute entry_key for name
       2. Look up `dict.get(&entry_key)` -- if Some(branches), decode branches[0] as ino via digest256_to_ino
       3. Return MetaError::NotFound if key not in dict
       NOTE: This is O(1) -- a single Dictionary lookup by name hash. No need to load the full entry list.

     - `pub fn list_dir_entries(dict: &impl StorageGet, dir_digest: &Digest224) -> Result<Vec<DirEntry>, MetaError>`
       1. Load entry list from dir_digest (get bytes, parse entry records)
       2. For each entry record: extract name string and entry_key, look up dict.get(&entry_key) to get ino
       3. Return Vec<DirEntry> with all entries

     Entry list serialization format: `[count: u32 LE][for each: entry_key (28 bytes Digest224) + name_len (u32 LE) + name_bytes]`
     Stored via State::push_all, retrieved via GetBytes.

     Unit tests for create, add, remove, lookup, list, . and .. presence, duplicate name rejection, remove . rejected
