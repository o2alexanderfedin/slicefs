1. Define the `WriteMode` enum above `OpenFileState` (per user decision: embed mode-specific data in variants to make illegal states unrepresentable):

```rust
/// Write mode for an open file handle.
///
/// Streaming mode is the default for sequential writes (O(log N) memory).
/// Buffered mode is a one-way fallback for non-sequential writes (O(N) memory).
/// Once a handle transitions to Buffered, it never reverts to Streaming.
enum WriteMode {
    Streaming {
        state: State,
        next_expected_offset: u64,
    },
    Buffered {
        buf: Vec<u8>,
    },
}
```

2. Refactor `OpenFileState` to use `WriteMode` instead of bare `state` field:

```rust
struct OpenFileState {
    ino: u64,
    write_mode: WriteMode,
    byte_count: u64,
    cas_committed: bool,
    last_committed_root: Option<Digest224>,
}
```

3. Update both `OpenFileState` construction sites (test_create at line 246 and open() at line 1137) to use `WriteMode::Streaming { state: State::default(), next_expected_offset: 0 }`.

4. Add `use tracing::debug;` import for logging fallback transitions.

Update all 5 dispatch methods to handle both WriteMode variants. Follow the locked decisions from CONTEXT.md exactly. Use the code examples from RESEARCH.md as reference but adapt to actual codebase patterns.

**test_write (line 263):**
- Streaming path: check `offset != *next_expected_offset`. If mismatch, trigger fallback transition:
  1. Clone State under open_files lock.
  2. Record byte_count, ino, last_committed_root.take().
  3. Drop open_files lock.
  4. Materialize: if byte_count > 0, clone+end+file_storage_get. If byte_count == 0, load committed manifest content via `self.meta.get_manifest(ino)` + `file_storage_get` (CRITICAL: prevents existing file content loss per Research Pitfall 1).
  5. Apply pwrite to buf (resize with zeros if offset+data.len > buf.len, copy_from_slice).
  6. Re-acquire open_files, swap write_mode to Buffered { buf }, update byte_count = buf.len() as u64, cas_committed = false.
  7. Decrement old committed root if Some.
  8. Return Ok(data.len() as u32).
  9. Add `debug!("fh={fh} ino={ino}: fallback from Streaming to Buffered mode (offset={offset}, expected={next_expected_offset})")` before transition.
- Streaming sequential path: push_bytes as before, increment next_expected_offset by data.len() as u64.
- Buffered path: standard pwrite into buf (resize+copy_from_slice), update byte_count = buf.len() as u64.

Lock ordering: open_files -> io (canonical). For fallback transition: release open_files before acquiring io for materialization. After materialization, re-acquire open_files to swap WriteMode. FUSE serializes per-fh writes so no race between release and re-acquire.

**test_release (line 292):**
- Extract from OpenFileState: match on write_mode to get either (state, byte_count, ...) or (buf, byte_count, ...).
- Streaming path: existing state.end() logic unchanged.
- Buffered path: if buf.is_empty() and not cas_committed, set empty manifest. Otherwise: create fresh State::default(), push_bytes(&buf), end(), fsa.end() to get Digest224. Then same refcount lifecycle as Streaming (decrement old if different, set manifest, increment new).

**test_read (line 371):**
- Check open_files for writer on this ino. If found in Buffered mode: clone buf directly (no clone+end CAS roundtrip needed). If found in Streaming mode: existing clone+end+file_storage_get path.
- Then slice [offset..offset+size] as before.

**flush_buffer_for_fsync (line 416):**
- Streaming path: existing clone+end logic unchanged.
- Buffered path: clone buf under open_files lock. Release lock. Under io lock: State::default() + push_bytes(&buf_clone) + end() + fsa.end() to get Digest224. Same refcount lifecycle (decrement old, increment new, set manifest). Re-acquire open_files to update last_committed_root and cas_committed.

**test_setattr_size (line 481):**
- Streaming path (Case A with open fh): existing materialize+resize+repush logic. But now must match WriteMode::Streaming to extract state.
- Buffered path (Case A with open fh):
  - new_size == 0: replace write_mode with Buffered { buf: Vec::new() }, byte_count = 0, take old_root for decrement.
  - new_size > 0: buf.resize(new_size as usize, 0), byte_count = buf.len() as u64. No CAS operations needed.
- Case B (no open fh): unchanged -- operates on committed content.

**Important details:**
- After every Buffered write/truncate: `byte_count = buf.len() as u64` (prevents drift per Research Pitfall 4).
- Only decrement last_committed_root once during transition (clear it with .take()).
- Materializing empty State (byte_count == 0): skip clone+end, use empty Vec or load from committed manifest.
- For the open() FUSE handler (line 1122): no changes needed -- it already creates Streaming mode, and O_TRUNC calls test_setattr_size which handles the new enum.
