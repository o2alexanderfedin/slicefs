This task wires the backend.rs module into the mount lifecycle and adds mount protection.

**1. Update `run_mount` signature** to accept backend and force:
```rust
pub fn run_mount(
    store_path: &Path,
    mountpoint: &Path,
    noatime: bool,
    allow_other: bool,
    _cache_size: usize,
    wal_strategy: Option<&str>,
    snapshot_ref: Option<&str>,
    auto_snapshot: bool,
    backend: Option<&str>,   // NEW
    force: bool,             // NEW
) -> Result<(), Box<dyn std::error::Error>>
```

**2. Add backend selection in `run_mount`** — BEFORE `load_store()`, after `check_mountpoint_not_in_use()`:

On macOS (`#[cfg(target_os = "macos")]`):
- Parse `backend` string to `FuseTBackend` via `parse_backend_flag` (if Some)
- Call `select_backend_auto(requested, force)` to get `(backend, version)` tuple
- Store result for later use in build_mount_options and startup logging

On non-macOS: skip backend detection entirely (Linux uses libfuse, not FUSE-T). Log "SliceFS mounted at {mountpoint}" without backend info.

**3. Update `build_mount_options`** to accept optional backend:
```rust
pub fn build_mount_options(noatime: bool, allow_other: bool, backend: Option<&FuseTBackend>) -> Config
```
When `backend` is Some, push `MountOption::CUSTOM(backend.as_mount_option().to_string())` to mount_options. All callers updated.

**4. Add fuse-t.ini fallback** — only on macOS, only when mount-option approach fails:
- Create `fn with_fuse_t_ini_backend<F, R>(backend: &str, f: F) -> Result<R, Box<dyn Error>>` that:
  1. Reads `/Library/Application Support/fuse-t/cfg/fuse-t.ini`
  2. Writes modified version with `backend=<value>` under `[Default]` section to `.tmp` file
  3. Atomic rename `.tmp` -> original
  4. Calls `f()` (the mount operation)
  5. ALWAYS restores original content (even on panic — use a Drop guard struct)
- The primary mount path (via CUSTOM option) is tried first. Only fall back to ini if the first mount2 attempt fails with a backend-related error. In practice, this will never trigger on FUSE-T 1.0.54+ but is present for completeness per user decision.

**5. Add signal handler** — register BEFORE `mount2()` call, macOS-only:
- Create a static `AtomicBool` (`SHUTDOWN_REQUESTED`) for signal-safe communication
- Create `unsafe fn register_signal_handlers()` using `libc::signal` for SIGTERM and SIGINT
- The handler sets `SHUTDOWN_REQUESTED` to true (signal-safe: only atomic store)
- Note: fuser already handles SIGTERM/SIGINT by ending the session. This is belt-and-suspenders for watchdog shutdown coordination.

**6. Add watchdog thread** — spawn BEFORE `mount2()`, shut down AFTER:
- Create `fn spawn_watchdog(mountpoint: PathBuf, interval: Duration, shutdown: Arc<AtomicBool>) -> std::thread::JoinHandle<()>`
- Follow the existing background GC thread pattern (Arc<AtomicBool> + sleep loop)
- Health check: `std::fs::metadata(&mountpoint)` — if returns Err (ENOENT, ENOTCONN-like), mount is dead
- Also check `SHUTDOWN_REQUESTED` static in the loop
- On failure: `eprintln!("[watchdog] mount health check failed -- forcing unmount")`, then `umount -f <mountpoint>`
- Use 5-second interval (more urgent than GC's 60s)
- After `mount2()` returns: set shutdown flag, join watchdog thread (same as GC shutdown pattern)

**7. Update startup logging** — replace `println!("SliceFS mounted at {}", ...)`:
- On macOS: `println!("SliceFS mounted at {} (backend: {}, fuse-t: {}.{}.{})", mountpoint.display(), backend_name, v.0, v.1, v.2)`
- On non-macOS: keep existing `println!("SliceFS mounted at {}", mountpoint.display())`

**8. Update `main.rs`** — wire `backend` and `force` through to `run_mount`:
- In `Cmd::Mount` match arm, pass `backend.as_deref()` and `force` to `run_mount()`
- Remove any temporary `let _ = (&backend, &force);` from Plan 01

**9. Update existing mount tests** — adjust `build_mount_options` calls to pass `None` for backend parameter (backward compat). Add new test:
- `test_build_mount_options_with_backend_smb`: verify CUSTOM("backend=smb") is in mount_options when backend=Some(Smb)
- `test_build_mount_options_no_backend`: verify no CUSTOM("backend=*") when backend=None

**Important notes:**
- All FUSE-T-specific code gated with `#[cfg(target_os = "macos")]`
- Signal handler uses `libc` (already a dependency) — NOT adding ctrlc crate per Claude's discretion
- Watchdog uses same Arc<AtomicBool> pattern as existing GC thread
- fuse-t.ini fallback uses Drop guard for guaranteed restoration
