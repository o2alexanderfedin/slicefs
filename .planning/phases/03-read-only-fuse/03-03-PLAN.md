<objective>
Implement the `slicefs mount` and `slicefs unmount` commands, completing the read-only FUSE filesystem lifecycle. The mount command loads a seeded store from disk, constructs the SliceFsFilesystem, and starts a blocking fuser::mount2 session. The unmount command shells out to fusermount3 -u. On session end (SIGTERM, Ctrl+C, or fusermount -u), the store is committed and Dictionary serialized back to disk.

Purpose: This is the final plan that turns SliceFS into a real mountable filesystem. After this, `slicefs seed` + `slicefs mount` produces a working read-only FUSE mount.
Output: Working mount and unmount commands; a human can seed a directory, mount it, and browse with ls/cat/stat.
</objective>

1. **Create `crates/slicefs-cli/src/mount.rs`:**

   a. `pub fn load_store(store_path: &Path) -> Result<(DictMetadataStore, Dictionary), Box<dyn std::error::Error>>`:
      - Read `<store_path>/root.bin` (must be exactly 28 bytes, otherwise error)
      - Parse root: read 7 x u32 LE -> Digest224
      - Read `<store_path>/dictionary.bin`
      - `let dict = deserialize_dictionary(&dict_bytes)?;`
      - Clone the dict for content reads: `let content_dict = dict.clone();`
      - `let meta = DictMetadataStore::load_from_root(dict, &root)?;`
      - Return `(meta, content_dict)`

      IMPORTANT: The Dictionary is cloned BEFORE passing to load_from_root, because load_from_root consumes the dict into the DictMetadataStore. The clone is used for content reads (GetBytes) in the SliceFsFilesystem.

   b. `pub fn build_mount_options(noatime: bool) -> Vec<MountOption>`:
      - Always include: `MountOption::RO`, `MountOption::FSName("slicefs".to_string())`, `MountOption::DefaultPermissions`
      - If noatime: add `MountOption::NoAtime`
      - Return the vec

   c. `pub fn run_mount(store_path: &Path, mountpoint: &Path, noatime: bool, _cache_size: usize) -> Result<(), Box<dyn std::error::Error>>`:
      - `let (meta, content_dict) = load_store(store_path)?;`
      - `let fs = SliceFsFilesystem::new(meta, content_dict);`
      - `let options = build_mount_options(noatime);`
      - `fuser::mount2(fs, mountpoint, &options)?;`
      - After mount2 returns (session ended), persist updated state:
        ```rust
        // mount2 has returned — session ended, destroy() already called
        // The SliceFsFilesystem was moved into mount2 and consumed.
        // destroy() already committed the root via meta.commit().
        // For Phase 3 read-only, no further persistence needed after mount2 returns.
        // Phase 4 will need post-session serialization when writes are introduced.
        ```
      - Note: `_cache_size` is accepted but not used in Phase 3. Placeholder for Phase 4.
      - Print a message before mount2: `println!("SliceFS mounted read-only at {}", mountpoint.display());`
      - Print after mount2 returns: `println!("SliceFS unmounted.");`

   d. **Post-session persistence (IMPORTANT for META-02):**
      The `destroy()` method on SliceFsFilesystem calls `meta.commit()` to commit the root. However, the Dictionary is NOT re-serialized to disk in destroy() because that would require filesystem I/O inside a FUSE callback. For Phase 3 (read-only), the dict doesn't change, so no re-serialization is needed. For Phase 4, this will need a post-mount2 serialization step.

      To still satisfy META-02 ("pending write flush"), destroy() commits the root (which is a no-op for read-only but proves the lifecycle works). The mount command logs the successful shutdown.

2. **Create `crates/slicefs-cli/src/unmount.rs`:**

   `pub fn run_unmount(mountpoint: &Path) -> Result<(), Box<dyn std::error::Error>>`:
   - Try `fusermount3 -u <mountpoint>` first (standard on modern Linux)
   - If fusermount3 not found, fall back to `fusermount -u <mountpoint>` (older systems)
   - If neither works, try `umount <mountpoint>` (requires root)
   - Check exit code, return error if all fail
   - Print success message on clean unmount

   ```rust
   use std::process::Command;

   pub fn run_unmount(mountpoint: &Path) -> Result<(), Box<dyn std::error::Error>> {
       let cmds = [
           ("fusermount3", vec!["-u", &mountpoint.to_string_lossy()]),
           ("fusermount", vec!["-u", &mountpoint.to_string_lossy()]),
           ("umount", vec![&mountpoint.to_string_lossy().to_string()]),
       ];
       for (prog, args) in &cmds {
           match Command::new(prog).args(args).status() {
               Ok(status) if status.success() => {
                   println!("Unmounted {}", mountpoint.display());
                   return Ok(());
               }
               _ => continue,
           }
       }
       Err(format!("Failed to unmount {}. Try: sudo umount {}", mountpoint.display(), mountpoint.display()).into())
   }
   ```
