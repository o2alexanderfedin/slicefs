  <action>
Implement `LocalDiskStore` in `disk_block_store.rs`:

Struct fields: `root: PathBuf`, `config: BlockStoreConfig`, `hasher: Box<dyn ContentHasher>`.

Constructor `new(root: PathBuf, config: BlockStoreConfig, hasher: Box<dyn ContentHasher>) -> Result<Self, CasError>` — creates root directory if it does not exist.

Internal helper `hash_to_path(&self, hash: &ChunkHash) -> PathBuf`:
- Convert hash to hex string via `hash.to_string()` (uses the Display impl with `{:02x}`)
- Split at position 2: prefix = first 2 chars, rest = remaining
- Return `self.root.join(prefix).join(rest)`

`put()` implementation:
1. Verify hash matches data: `self.hasher.hash(data) == hash`. If not, return `IntegrityFailure`.
2. Compute path via `hash_to_path`.
3. If file already exists, return `Ok(())` (idempotent). Optionally verify stored content matches for collision detection.
4. Create parent directory (`fs::create_dir_all`).
5. Write data to file atomically: write to `.tmp` file, then `fs::rename` to final path. This prevents partial writes from appearing as valid blocks.

`get()` implementation:
1. Compute path. If file does not exist, return `NotFound`.
2. Read all bytes.
3. If `config.verify_on_read`, re-hash bytes and compare to provided hash. Return `IntegrityFailure` on mismatch.
4. Return bytes.

`exists()`: check if path exists via `Path::exists()`.

`delete()`: remove file if it exists. Idempotent. Do not remove parent directory (avoid race with concurrent writes).

Write `#[cfg(test)]` module using `tempfile::TempDir` for all tests. Import `Blake3Hasher` from sibling module. Include the corruption test: write a block, use `std::fs::write` to overwrite the file with garbage, assert `get()` returns `IntegrityFailure`. Use `proptest` for round-trip property test.

  <action>
Implement `MemDedupIndex` in `mem_dedup_index.rs`:

Struct fields: `bloom: RwLock<BloomFilter>`, `present: RwLock<HashSet<ChunkHash>>`.

Constructor `new(expected_items: usize, false_positive_rate: f64)` — creates bloom filter via `fastbloom::BloomFilter::with_false_pos(fpr).expected_items(n)`.

`bloom_check()`: read-lock bloom, call `contains(hash.as_bytes())`.

`lookup()`: call `bloom_check()` first. If false, return `DefinitelyAbsent`. If true, read-lock `present` set. If found, return `Present`. If not found, return `Absent` (bloom false positive).

`insert()`: write-lock bloom, insert `hash.as_bytes()`. Write-lock present, insert hash clone.

`remove()`: write-lock present, remove hash. Do NOT update bloom (bloom filter does not support deletion; false positives from removed hashes are tolerated per the trait design — they just cause an unnecessary authoritative lookup).

Add inherent methods (not on the trait):
- `save_to_writer(&self, writer: &mut impl Write) -> Result<(), CasError>` — serialize bloom filter using `serde` + `bincode`. Also serialize the present set.
- `load_from_reader(reader: &mut impl Read) -> Result<Self, CasError>` — deserialize.

Note: The `fastbloom::BloomFilter` supports serde. If serialization is complex, a simpler approach is acceptable for Phase 1 — document the limitation and note that the owner's adapter will handle production persistence.

Write `#[cfg(test)]` module with all behavior tests. For the bloom false positive demonstration test: insert 10000 random hashes, then check 10000 different random hashes — assert at least one triggers `bloom_check=true` but `lookup` returns `Absent`. Use `proptest` for the "all inserted hashes are findable" property test. For thread safety, use `std::thread::scope` with concurrent inserts and lookups.
