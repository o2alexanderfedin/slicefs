    - test_refcount_decrement_saturated: set refcount to u64::MAX, decrement is a no-op, refcount stays u64::MAX
    - test_saturated_refcount_count: store with 2 saturated and 3 normal refcounts returns saturated_refcount_count() == 2
    - test_inode_count_empty: fresh DictMetadataStore has inode_count() == 1 (root inode)
    - test_inode_count_tracks_lifecycle: create 3 inodes -> inode_count() == 4, delete 1 -> inode_count() == 3
    - test_inode_count_after_reload: create inodes, commit, load_from_root -> inode_count matches original
  </behavior>
  <action>
**FIX-01 — Refcount saturation:**

1. Rewrite `increment_refcount` (line 140-143): Replace `*rc.entry(*digest).or_insert(0) += 1` with:
   - Get mutable entry via `rc.entry(*digest).or_insert(0)`
   - If `*val == u64::MAX`, return early (already saturated)
   - Otherwise `*val += 1`
   - If the new value is `u64::MAX`, log `tracing::warn!("refcount saturated for block — block is now immortal and will not be GC'd")`

2. Add saturation guard to `decrement_refcount` (line 149-158): As the **first** check inside the `if let Some(count)` block, add `if *count == u64::MAX { return; }` before any arithmetic.

3. Add new public method `pub fn saturated_refcount_count(&self) -> usize` that locks refcounts and counts entries where `value == u64::MAX`.

**FIX-02 — inode_count AtomicU64:**

4. Add `inode_count: AtomicU64` field to `DictMetadataStore` struct (after `logical_bytes`).

5. In `DictMetadataStore::new()`: initialize `inode_count: AtomicU64::new(1)` (root inode is created in new()).

6. In `create_inode()`: after the inode is inserted, add `self.inode_count.fetch_add(1, Ordering::Relaxed)`.

7. In `delete_inode()`: after the inode is removed, add `self.inode_count.fetch_update(Ordering::Relaxed, Ordering::Relaxed, |c| Some(c.saturating_sub(1))).ok()`.

8. In `load_from_root()`: after `inode_data` BTreeMap is populated, set `inode_count: AtomicU64::new(inode_data.len() as u64)`.

9. Add public getter: `pub fn inode_count(&self) -> u64 { self.inode_count.load(Ordering::Relaxed) }`.

**Tests:** Add all behavior tests above in the existing `#[cfg(test)] mod tests` block at the bottom of store.rs. For the saturated refcount tests, directly set values via `rc.insert(*digest, u64::MAX)` after getting the lock, then call the public methods.
  </action>

  </verify>

    - saturated_refcount_count() returns correct count
