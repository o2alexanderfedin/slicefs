- CONTEXT specific (Docker): the Docker VM is low on memory: `cargo build -j 1`; every committed Docker log shows `build-exit=0`.
- Claude's discretion (this plan decides): the field names and the line layout below; the section name `FMT-02`. Reversible, no checkpoint.
