       ```rust
       /// Mount a specific snapshot read-only (by version number or name).

       #[arg(long, default_value_t = false)]
       auto_snapshot: bool,
       ```

    3. Create `crates/slicefs-cli/src/snapshot.rs`:

       **run_snapshot_create(store_path, name)**:
       - Check mount.lock — refuse if mounted (snapshot create on live store is unsafe without IPC; per RESEARCH.md recommendation, require unmount for Phase 6)
       - Load segments to get (dict, root, snapshots)
       - Reconstruct DictMetadataStore, set_snapshots
       - Create WAL (PerOp strategy, next segment ID)
       - Call meta.create_snapshot(name)
       - Shutdown WAL
       - Print: "Snapshot {version} created (root: {hex_root})"

       **run_snapshot_list(store_path)**:
       - Load segments to get (dict, root, snapshots)
       - Print header: "Version | Name | Created | Root"
       - For each snapshot: print formatted row. created_at formatted as ISO 8601 datetime.
       - Print total count

       **run_snapshot_switch(store_path, version_or_name)**:
       - Check mount.lock — refuse if mounted
       - Load segments to get (dict, root, snapshots)
       - Reconstruct DictMetadataStore, set_snapshots
       - Find target snapshot by version_or_name (try parse u64 first, then name)
       - If not found, error "snapshot not found: {version_or_name}"
       - Auto-snapshot current state: create_snapshot(Some("auto-before-switch"))
       - Write RootUpdate with snapshot root to a new segment (this makes next mount load from that root)
       - Shutdown WAL
       - Print: "Switched to snapshot {version} (auto-snapshot {auto_version} saved)"

    4. Update `run_mount` in `mount.rs`:
       - Accept `snapshot_ref: Option<&str>` and `auto_snapshot: bool` params
       - If snapshot_ref is Some: after load_store, find snapshot, call `DictMetadataStore::load_from_root(dict, &snap.root)`, add `MountOption::RO` to config. Print: "Mounting snapshot {version} (read-only)"
       - If auto_snapshot: in the cleanup section after `mount2` returns (before GC shutdown), call `meta.create_snapshot(Some("auto-unmount"))` and print the version.
       - Note: auto_snapshot interacts with the existing destroy() call. Since destroy() calls shutdown_wal(), the auto-snapshot must happen BEFORE destroy(). The executor needs to check if `mount2` calls `destroy()` automatically or if it's manual. If `mount2` triggers `Filesystem::destroy()` which shuts down WAL, then auto-snapshot must be done inside `destroy()` (add auto_snapshot flag to SliceFsFilesystem).

    5. Update `main.rs` to route `Cmd::Snapshot { action }` to the appropriate run_ function.

    6. Add `pub mod snapshot;` to `lib.rs`.
