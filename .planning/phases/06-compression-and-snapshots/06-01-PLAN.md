<task type="auto" tdd="true">
  <name>Task 2: slicefs-compression crate with Zstd, LZ4, None implementations</name>
  <files>crates/slicefs-compression/Cargo.toml, crates/slicefs-compression/src/lib.rs, crates/slicefs-compression/src/zstd_compressor.rs, crates/slicefs-compression/src/lz4_compressor.rs, crates/slicefs-compression/src/none_compressor.rs, Cargo.toml</files>
  <behavior>
    - ZstdCompressor::new(3) compresses "aaaa...a" (1000 bytes) to fewer bytes
    - ZstdCompressor with random 1000 bytes returns (AlgorithmId::Raw, original_bytes)
    - Lz4Compressor::new() compresses "aaaa...a" (1000 bytes) to fewer bytes
    - Lz4Compressor with random 1000 bytes returns (AlgorithmId::Raw, original_bytes)
    - NoneCompressor::compress returns (AlgorithmId::None, input.to_vec()) always
    - NoneCompressor::decompress(AlgorithmId::None, data) returns data unchanged
    - All compressors: compress then decompress returns identical input bytes
    - compress_block prepends 1-byte AlgorithmId header; decompress_block strips it
    - compress_block + decompress_block round-trips for all compressors
    - Empty input: compress([]) + decompress round-trips to empty
    - ZstdCompressor default level is 3; Lz4Compressor default is acceleration 1
  </behavior>
  <action>
    1. Add workspace dependencies to root `Cargo.toml`:
       ```toml
       zstd = "0.13"
       lz4_flex = "0.13"
       ```

    2. Add `"crates/slicefs-compression"` to workspace members.

    3. Create `crates/slicefs-compression/Cargo.toml`:
       - name = "slicefs-compression"
       - dependencies: slicefs-traits (path), zstd (workspace), lz4_flex (workspace)
       - dev-dependencies: (none extra needed)

    4. Create `zstd_compressor.rs`:
       - `ZstdCompressor { level: i32 }` with `new(level: i32)` and `Default` (level=3)
       - `compress`: call `zstd::encode_all(input, self.level)`. If compressed.len() >= input.len(), return (AlgorithmId::Raw, input.to_vec()). Otherwise (AlgorithmId::Zstd, compressed).
       - `decompress`: match on algorithm — Zstd calls `zstd::decode_all`, Raw returns input.to_vec(), None returns input.to_vec(), anything else errors
       - `algorithm_id`: returns AlgorithmId::Zstd

    5. Create `lz4_compressor.rs`:
       - `Lz4Compressor {}` with `new()` and `Default`
       - `compress`: call `lz4_flex::block::compress_prepend_size(input)`. If compressed.len() >= input.len(), return (AlgorithmId::Raw, input.to_vec()). Otherwise (AlgorithmId::Lz4, compressed).
       - `decompress`: match on algorithm — Lz4 calls `lz4_flex::block::decompress_size_prepended`, Raw/None return input.to_vec(), anything else errors
       - `algorithm_id`: returns AlgorithmId::Lz4

    6. Create `none_compressor.rs`:
       - `NoneCompressor {}` with `new()`
       - `compress`: always returns (AlgorithmId::None, input.to_vec())
       - `decompress`: for None/Raw, returns input.to_vec(); for Zstd/Lz4, returns CompressorError (cannot decompress)
       - `algorithm_id`: returns AlgorithmId::None

    7. Create `lib.rs`:
       - Re-export all three compressor types
       - `compress_block(compressor: &dyn Compressor, raw: &[u8]) -> Vec<u8>`: calls compress, prepends 1-byte AlgorithmId header. On error falls back to Raw.
       - `decompress_block(compressor: &dyn Compressor, wire: &[u8]) -> Result<Vec<u8>, CompressorError>`: reads first byte as AlgorithmId, calls decompress on remaining bytes. Empty wire returns empty Vec.
       - `parse_compressor(name: &str, level: Option<i32>) -> Box<dyn Compressor>`: factory function — "zstd" | "lz4" | "none". Defaults: zstd level 3, lz4 default. Used by CLI.

    All implementations must handle empty input gracefully (empty compress -> empty + header; empty decompress -> empty).
  </action>

  </verify>
  <done>All three compressors pass round-trip, incompressible detection, wire format helpers work, workspace builds clean</done>
</task>
