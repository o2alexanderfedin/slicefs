    let payload = entry.payload_bytes();
    let record_type = entry.record_type() as u8;
    let payload_len = payload.len() as u32;
    self.inner.write_all(&[record_type])?;

    Ok(())

<task type="auto" tdd="true">
  <name>Task 2: DictMetadataStore snapshot methods</name>
  <files>crates/metadata/src/store.rs</files>
  <behavior>
    - create_snapshot() calls commit() then writes SnapshotRecord to WAL, returns SnapshotEntry
    - create_snapshot() auto-increments version from max existing + 1 (starts at 1)
    - create_snapshot() with name=Some("tag") stores the name
    - list_snapshots() returns all snapshots sorted by version ascending
    - find_snapshot("tag") finds by name; find_snapshot("3") finds by version
    - snapshot_roots() returns vec of all snapshot roots + current live root
    - snapshot_roots() with no snapshots returns vec![current_root] (or empty if no root)
    - Snapshots survive segment replay: create snapshot, reload from segments, list still shows it
    - set_snapshots() loads snapshot list during store reconstruction
  </behavior>
  <action>
    1. Add `snapshots: Mutex<Vec<SnapshotEntry>>` field to `DictMetadataStore`.

    2. Add `set_snapshots(&mut self, snapshots: Vec<SnapshotEntry>)` — called during store reconstruction from segments (in mount.rs load_store, after load_store_from_segments returns the snapshot list).

    3. Add `create_snapshot(&self, name: Option<String>) -> Result<SnapshotEntry, MetaError>`:
       - Call `self.commit()` to flush all in-memory state and get stable root
       - Compute version = max(existing versions) + 1, or 1 if none
       - created_at = SystemTime::now() as unix timestamp seconds
       - Build SnapshotEntry { version, name, root, created_at }
       - Write SegmentEntry::SnapshotRecord to WAL (same as commit writes RootUpdate)
       - Push entry into self.snapshots
       - Return entry

    4. Add `list_snapshots(&self) -> Vec<SnapshotEntry>`:
       - Lock snapshots, clone and return sorted by version

    5. Add `find_snapshot(&self, reference: &str) -> Option<SnapshotEntry>`:
       - Try parsing as u64 (version lookup)
       - If not a number, try name lookup
       - Return first match

    6. Add `snapshot_roots(&self) -> Vec<Digest224>`:
       - Collect all snapshot roots + current_root into a Vec
       - Used by GC (both background and offline)

    7. Update mount.rs `load_store` to call `meta.set_snapshots(snapshots)` after reconstructing the store (where `snapshots` comes from `load_store_from_segments`).

    Write tests in store.rs module tests exercising create, list, find, snapshot_roots.
