rule.rs (D-11, D-12):
- `boundary_hash(level, key)`: a `blake3::Hasher` fed the single byte `level.wrapping_add(1)` and then the key; the first 4 bytes of the digest as `u32::from_le_bytes`. Doc: computed over the key only, never the value; the level byte is the salt per level (RESEARCH Pitfall 2).
- `exp_neg(x)` for x >= 0, `pub(crate)`: if x >= 40.0 return 0.0; else halve x until it is below 0.5, counting the halvings k; sum the Taylor series of e^(-y) for 16 terms in a fixed order; square the result k times. Only `+ - * /` on f64; no float function from std, and name none of them in a comment of rule.rs (the acceptance grep counts them) (RESEARCH: the std exponential is documented as not the same on every platform, and node IDs depend on every cut).
- `cut_probability(cfg, before, after)`: s4(s) = s * s * s * s in u64 (after <= NODE_MAX = 2^14, so at most 2^56); delta = (s4(after) - s4(before)) as f64 divided by s4(weibull_l) as f64; return 1.0 - exp_neg(delta). Doc: this is Dolt's (F(after) - F(before)) / (1 - F(before)) for the Weibull CDF F with K=4.
- `Splitter { size, count }`: `new()` gives size = NODE_HEADER and count = 0. `push(cfg, level, key, entry_len)` in exactly this order: before = size; size += entry_len; count += 1; if level > 0 and count < 2 return false (an internal node never ends after its first entry); if size > cfg.force_at() return true; if size < cfg.node_min return false; else return `(boundary_hash(level, key) as f64 / 4_294_967_295.0) < cut_probability(cfg, before, size)`. `reset()` back to `new()`. Doc: the decision reads only the bytes and entries since the last cut and the hash of the current key, with no look-ahead, so a rebuild may restart at any node start.

node.rs (D-14), crate-private:
- `Child { last_key: Vec<u8>, id: ObjectId, count: u64 }`; `Node::Leaf(Vec<(Vec<u8>, Vec<u8>)>)` and `Node::Internal { level: u8, children: Vec<Child> }`.
- `leaf_entry_len(k, v) = 4 + k + v` (klen u16 LE, vlen u16 LE, key, value); `internal_entry_len(k) = 2 + k + ID_LEN + 8` (klen u16 LE, key, child id 33 bytes, subtree entry count u64 LE). Header: `NODE_MAGIC`, level u8, entry count u32 LE.
- `encode_leaf(&[(Vec<u8>, Vec<u8>)]) -> Vec<u8>`, `encode_internal(level, &[Child]) -> Vec<u8>`.
- `decode(bytes) -> Result<Node>`: never panics and uses no `unwrap` on input bytes; every offset uses `checked_add` and a bounds check. It returns `Error::Corrupt(..)` for: fewer bytes than the header; a wrong magic; an internal node with count 0; a count that cannot fit in the remaining bytes (check `count <= remaining / smallest entry` before any allocation); an entry that runs past the end; bytes left after the last entry; a key above `MAX_KEY`; keys that are not strictly ascending.
- `load(store, id, want_level: Option<u8>) -> Result<Node>`: `store.read(id)` (hash-verified), then `decode`, then a level other than `want_level` is `Error::Corrupt("child at wrong level ..")`.

tree.rs (D-02, D-15, D-16):
- `NodeRef { last_key, id, count, bytes }` (count = leaf entries under the node; bytes = encoded length).
- `LevelWriter { level, splitter, leaf entries or children, buffered_bytes, count }` with `push_leaf(store, cfg, key, value, stats) -> Result<Option<NodeRef>>`, `push_child(store, cfg, child, stats) -> Result<Option<NodeRef>>`, `flush(store, stats) -> Result<Option<NodeRef>>`, `is_empty()`, `buffered_bytes()`. Every entry goes through `Splitter::push`; on a cut the node is encoded, put with `store.put`, counted in `nodes_written` and `bytes_written` (bytes passed to put; dedup may store fewer), and returned; the splitter is reset. An empty buffer flushes to `None` (no empty node is written).
- `BuildStats { nodes_written: u64, bytes_written: u64, high_water_bytes: usize, depth: u8, leaves: u64, entries: u64 }` (depth = number of levels: 1 for one leaf).
- `Builder<'s> { store: &'s ChunkStore, cfg: Config, levels, last_key: Option<Vec<u8>>, stats }`. `new(store, cfg)`. `push(key, value)`: `Error::KeyTooLarge` if the key is above `cfg.max_key`; `Error::EntryTooLarge` if `leaf_entry_len` is above `cfg.max_entry`; `Error::Unsorted` if the key is not above the last key; all three before anything is buffered. A `NodeRef` emitted by a level becomes a `Child` pushed into the next level (made when first needed). After each push, `high_water_bytes` = max(itself, the sum of `buffered_bytes()` over all levels). `pub(crate) fn with_level(store, cfg, level)` and `pub(crate) fn push_node(&mut self, r: NodeRef) -> Result<()>` let plan 24-02 build new top levels from nodes of an existing level through the same code.
- `finish(self) -> Result<(ObjectId, BuildStats)>`: from the base level up, flush the in-progress node of the level. If the level has emitted exactly one node in total, that node is the root (the level above then holds only that one child in its buffer and has never cut, because an internal node never ends after its first entry), and no node above it is written. Else continue with the next level. No entries at all: the root is `empty_root(store)`. So the root is canonical: never an internal node with one child.
- `empty_root(store)`: put the encoded empty leaf (level 0, count 0) and return its ID.
- `build(store, cfg, entries)` over `IntoIterator<Item = (K, V)>` with `K: AsRef<[u8]>, V: AsRef<[u8]>`.
- `get(store, root, key) -> Result<Option<Vec<u8>>>`: load the root; while internal, binary search for the first child whose last key is >= key (none: `Ok(None)`) and load it with `want_level = level - 1`; at the leaf, binary search the key.
