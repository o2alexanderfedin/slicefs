<objective>
Build the driver of PROLLY-02: `scripts/prolly-bench/bench.sh` and its README, in the pattern of `scripts/chunk-profiles/bench.sh`, plus a no-FUSE Docker mode. The script turns the per-commit lines of `prolly-bench` into CSV files with median rows, records the machine, and has a SMOKE mode on generated data. Plan 24-05 runs it on the Boost trees.

Task 1 (tracer) wires the SMOKE path end to end: generated trees, one seed, one run of `whole`, `batches`, `flat` and `prolly`, `results.csv` with median rows and `machine.txt`. Task 2 adds the other output files, the scale rows, the full-mode checks and refusals, the cleanup check and the README, and commits the macOS smoke CSV. Task 3 adds the Docker mode, runs the Linux smoke (with the prolly tests, so the golden root is checked on Linux), and runs the plan gates.

Decisions this plan implements: D-02 (bench processes stay bounded; the script holds no data in RAM), D-06, D-07, D-20, D-21 (the seeded, recorded edit script parameters), D-23 (medians of several runs, peak RSS per process), D-24 (the README separates serialized from stored bytes), D-29 (the machine-readable `bench_data` marker that plan 24-05 needs).

Discretion choices (reversible, recorded in the SUMMARY): the six output files and their columns (below); `median_low` over every run row of a (mode, pattern, k) group, `seq=all` on the median row; the store copy is a clone where the file system can (`cp -cR` on macOS, `cp -a --reflink=auto` on Linux) and a plain copy otherwise; SMOKE defaults `KS="1 10" COMMITS=2 SCALE_NS="10000 50000"` and trees of 2,000 and 2,100 files of up to 4 KiB.

Purpose: ROADMAP criterion 2 (a reproducible benchmark that runs outside the test suite).
Output: the script, the README, the Docker mode, smoke results for macOS and Linux, `runs/gate-24-04.log`.
</objective>
