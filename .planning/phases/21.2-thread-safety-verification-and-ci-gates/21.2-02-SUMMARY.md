# Phase 21.2 Plan 02: Race (b), the rename into the own subtree Summary

A cross-directory rename of a directory now walks the `..` chain of the target parent under the rename mutex and returns `EINVAL` when the moved directory is on it, so a directory can no longer leave the tree as a detached cycle with its children.

## What was built

- `filesystem.rs`: `fn check_not_ancestor(&self, dir, target_parent) -> Result<(), i32>` and the private const `MAX_ANCESTOR_STEPS = 1 << 20`. The walk starts at `target_parent`, returns `EINVAL` when it meets `dir`, reads `..` with `self.meta.lookup(cur, "..")` (an error maps through `meta_error_to_errno`), ends at the root (its `..` is itself) and returns `ELOOP` after the step guard.
- `rename_held` calls it right after `src_is_dir` is known and before the `RENAME_NOREPLACE` check, only for a directory moved to another parent. `lock_namespace` holds the rename mutex there. Nothing is written before the call, so a refused rename appends no record. No new `Op`, no store change (`git diff 57bf731 -- crates/slicefs-cli/src/oplog.rs crates/metadata/src` is empty).
- `tests/rename_ancestor_tests.rs` (in process, through `simulate_rename` and `handlers::handle_rename`, D-28):
  - `a_directory_cannot_move_into_its_own_subtree`, `a_directory_cannot_move_into_itself`, `a_deep_move_into_the_subtree_is_refused`: `EINVAL`. No entry, `..` or link count changes.
  - `the_root_is_its_own_parent`: `lookup(1, "..") == 1` (RESEARCH A7 holds).
  - `moves_that_make_no_cycle_still_work`: directory across directories, directory up to the root, file across directories, directory renamed in the same directory.
  - `a_refused_rename_writes_no_record`: per-op write log, `log_len` is the same before and after.
  - `stress_cross_directory_directory_renames_keep_one_tree`: 12 directories (depth 1 to 3), 4 std threads on an `Arc`, 150 renames each, half of the targets in the current subtree of the moved directory (or the directory itself), allowed results Ok, EINVAL, ENOENT, EEXIST, ENOTEMPTY. After the join, each directory is reached from the root exactly once and its `..` chain reaches the root in at most 12 steps. Seed `0x2102`. No ignore attribute. Each test-side walk has a bound, so a cycle gives a failed assert, not a hang.
